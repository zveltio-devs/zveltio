# Security policy

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub
issues, Discussions or Discord.

Email **security@zveltio.com** instead. Include:

- the affected component (engine, Studio, SDK, CLI, or an extension) and version;
- steps to reproduce, or a proof of concept;
- the impact you expect (data exposure, privilege escalation, cross-tenant access, …).

We respond within 48 hours on business days.

## Supported versions

Zveltio is in beta. Fixes land in the latest release only, so please
reproduce against it before reporting.

## Scope

This policy covers this repository and the first-party extensions in
[`zveltio-devs/zveltio-extensions`](https://github.com/zveltio-devs/zveltio-extensions).
For how isolation, permissions and multi-tenancy are designed, see
[`docs/platform/security-model.md`](docs/platform/security-model.md).
